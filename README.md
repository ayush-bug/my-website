# Portfolio 
 
  This is my personal portfolio buid to showcase my skills , projects , and about me .

  I have created this website in react because I wanted to use some interactive components .


  It is a dark themed web site with interactive animation and react components.

## run locally

- clone the repository 
  <pre>
  https://github.com/ayush-bug/my-website.git
  </pre>
- Install dependencies 
  <pre>
  npm install
  </pre>
- start the devlopment server
   <pre>
   npm run dev
   </pre>
